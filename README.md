Steps Completed

Watched a beginner tutorial on Cursor by Tech with Tim on YouTube to familiarise myself with the IDE and its interface.
Downloaded and installed Cursor on my laptop.
Attempted to install the Claude Code and Codex extensions directly from the Cursor marketplace — neither appeared in search results.
Googled why extensions might not be visible and found a relevant thread on the Cursor community forum.
Following forum advice, used an external VSIX downloader to manually download the extension files.
Was unsure how to install the downloaded files, so researched the process and learned about the "Install from VSIX" method.
Opened the Cursor command palette (Cmd + Shift + P), selected "Install from VSIX", and pointed it to the downloaded files.
Moved the extension files into my working folder as required, and Cursor completed the installation.
Reloaded the Cursor window to confirm the extensions were active.
